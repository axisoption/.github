# Contributing to AxisOption GitHub Resources

Thank you for your interest in AxisOption.

This `.github` repository primarily maintains the **public AxisOption organization profile, visual assets, and organization-wide community guidance**. It is not the source repository for the production trading platform or private infrastructure.

## Before contributing

Please first identify the type of request:

- **Client or account support:** use https://axisoption.com/contact.html
- **Partner or business enquiry:** use https://axisoption.com/partners.html
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md) and report privately
- **Public documentation/profile correction:** a GitHub contribution may be appropriate where repository contribution features are available

## Public documentation contributions

When proposing a correction or improvement to public documentation:

1. Keep the change focused and easy to review.
2. Use clear, professional English.
3. Link claims about AxisOption products or services to an official AxisOption source where practical.
4. Do not add performance promises, guaranteed-return language, unsupported statistics, or unverified regulatory claims.
5. Do not include credentials, user data, internal infrastructure details, private endpoints, or proprietary trading logic.
6. Respect existing brand terminology and public product naming.

## Product code and private systems

The production AxisOption platform, proprietary systems, private configuration, credentials, operational data, and security-sensitive infrastructure are not maintained as public contributions through this profile repository.

Unsolicited submissions containing secrets, copied proprietary code, user information, or material belonging to third parties should not be posted.

## Communication standard

Keep discussions professional, specific, and relevant to the proposed change. Technical disagreement is welcome; harassment, spam, impersonation, deceptive promotion, or disclosure of private information is not.
